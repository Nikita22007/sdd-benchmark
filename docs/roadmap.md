# План

## Сделано

- Детерминированные агенты `frugal`, `greedy`, `sloppy` — без моделей и сети.
- Сценарии в TOML: имя, цель, фрагмент проверки.
- Команда `run` пишет JSON в `results/`, код возврата отражает исход проверки.
- Команда `report` сводит результаты в таблицу по агентам.

## Ближайшее

- Сценарии с несколькими проверками на один прогон.
- Учёт времени выполнения по этапам (подготовка, работа агента, проверка).
- Сравнение пар «агент × сценарий» в одной таблице.

## Дальше

- Замена фрагмента проверки на полноценные тесты сценария.
- Адаптер реальной модели за тем же интерфейсом `Agent`, чтобы стенд можно было
  сравнить с детерминированной базой.
- Ограничение времени на прогон и явный исход «превышен лимит».

## Вне рамок

- Оценка качества кода моделью.
- Изоляция процессов и прав.
- Поддержка произвольных языков и экосистем.
