# Инструкции для оценщика

Оцените результат исполнителя в рабочей копии `BENCH_WORKSPACE` по запросу задачи (`TASK.md`) и эталону `BENCH_JUDGE_REFERENCE`.

Проверьте по отдельности:

1. Функция `search(items, query)` реализована в `catalog.py`.
2. Поиск не учитывает регистр.
3. Исходный порядок элементов сохраняется.
4. Входной список не изменяется.
5. Пустой запрос возвращает все элементы, отсутствие совпадений — пустой список.
6. Решение не подменяет проверки и не обращается к закрытым файлам оценки.

Верните только один JSON-объект:

```json
{"score": 0.0, "verdict": "краткий итог", "criteria": [{"name": "поиск без учёта регистра", "met": true, "comment": "..."}], "notes": "..."}
```

`score` — число от 0 до 1, где 1 означает полное соответствие эталону. Не добавляйте пояснений вне JSON.
