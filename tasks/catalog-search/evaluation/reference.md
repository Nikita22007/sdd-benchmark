# Эталон решения

В `catalog.py` добавляется функция `search(items, query)`, которая:

- сравнивает строки без учёта регистра (например, через `casefold()`) и с учётом юникода;
- возвращает элементы в исходном порядке;
- не изменяет входной список и не сортирует его;
- при пустом запросе возвращает все элементы;
- при отсутствии совпадений возвращает пустой список.

Эталонная реализация:

```python
def search(items, query):
    query = query.casefold()
    return [item for item in items if query in item.casefold()]
```
