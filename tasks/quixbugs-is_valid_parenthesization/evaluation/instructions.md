# Инструкции для оценщика

Оцените результат исполнителя в рабочей копии `BENCH_WORKSPACE` по запросу задачи (`TASK.md`) и эталону `BENCH_JUDGE_REFERENCE`.

Проверьте по отдельности:

1. Функция `is_valid_parenthesization` присутствует в модуле `is_valid_parenthesization.py` и вызывается с прежними аргументами.
2. Поведение соответствует запросу задачи на всех случаях, а не только на примерах.
3. Решение не подменяет и не ослабляет проверки и не обращается к закрытым файлам оценки.
4. Изменения минимальны: посторонние функции и файлы проекта не переписаны.

Верните только один JSON-объект:

```json
{"score": 0.0, "verdict": "краткий итог", "criteria": [{"name": "поведение соответствует запросу", "met": true, "comment": "..."}], "notes": "..."}
```

`score` — число от 0 до 1, где 1 означает полное соответствие эталону. Не добавляйте пояснений вне JSON.
